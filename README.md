# Creatofly Daily Task Management

A role-based daily task management web app built for Creatofly's internship team using React and Next.js App Router.

## Features

- Dashboard for tracking daily progress
- Create, edit, complete, and delete tasks
- My Tasks and Assigned Tasks views
- Role-based access for Team Members and Reviewers
- Task filtering and progress tracking
- Demo user selector
- LocalStorage for saving task data
- Responsive UI

## Tech Stack

- React
- Next.js
- JavaScript
- LocalStorage
- CSS

## Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd creatofly-daily



2. Install dependencies
npm install
3. Start the development server
npm run dev
4. Open the app

Open:http://localhost:3000

Note: This project uses a demo user selector instead of real authentication. Task data is stored locally in the browser using LocalStorage.
